# AI Commit Gate — Review Reports

Runtime markdown reports from the pre-commit AI commit gate.

| File | Meaning |
|------|---------|
| `latest.md` | Most recent review (overwritten each run) |
| `YYYYMMDD-HHMMSS-<hash12>.md` | Archive per run |

Generated by `print_ai_review.py` when `AI_GATE_REPORT_DIR` is set (default: this directory).

These `*.md` result files are gitignored — only this README is tracked.
